# 🍽️ Recipes Finder App

A modern **React-based web application** that allows users to search, explore, and discover a wide variety of recipes using an external recipes API. The app provides an easy-to-use interface where users can find recipes by entering keywords and instantly view relevant results.

🔗 **Live App:** [https://kmq8h7.csb.app/](https://kmq8h7.csb.app/)

## 📌 Project Overview

The **Recipes Finder App** is designed to help users quickly find cooking recipes without browsing multiple websites. By simply entering a recipe name or ingredient, users can explore recipes along with essential details.

This project demonstrates practical frontend development skills such as **API integration**, **React hooks**, **component-based architecture**, and **responsive UI design**.

---

## 🚀 Features

* 🔍 **Search Recipes** by name or keyword
* 📋 **Dynamic Recipe Listing** fetched from an external API
* ⚡ **Real-time Results** based on user input
* 🧩 **Reusable React Components**
* 📱 **Responsive Design** for different screen sizes
* 🎨 **Clean and User-Friendly UI**

---

## 🛠️ Technologies Used

* **JavaScript (ES6+)** – Core logic
* **HTML5** – Structure
* **CSS3** – Styling
* **External Recipe API** – Fetching recipe data
* **CodeSandbox** – Development & deployment

---

## ⚙️ How the Website Works

1. The user enters a **recipe name or keyword** in the search input.
2. On search, the app sends a request to the **recipe API**.
3. The API returns a list of matching recipes.
4. The app dynamically displays the recipes on the UI.
5. Users can browse and explore different recipes easily.

## ▶️ How to Run the Project Locally

If you download or clone this project from GitHub and want to run it on your system using **VS Code**, follow the simple steps below. These are the same steps I use while working on the project.

### 1️⃣ Download or Clone the Repository

You can get the project in two ways:

* Click on the **Code** button on GitHub and choose **Download ZIP**, then extract it, or
* Clone the repository using Git:

```bash
git clone https://github.com/AnujBhagat08/RECIPES_FINDER_AAP.git
```

### 2️⃣ Open the Project in VS Code

* Open **VS Code**
* Click on **File → Open Folder**
* Select the extracted/cloned project folder

### 3️⃣ Install Required Packages

Once the project is open, open the terminal in VS Code and run:

```bash
npm install
```

This command will install all the necessary dependencies needed to run the app.

### 4️⃣ Run the Project

After the installation is complete, start the development server by running:

```bash
npm start
```

or (depending on the setup):

```bash
npm run dev
```

### 5️⃣ Open in Browser

After the server starts, the app will open automatically in your browser.
If not, you can manually open it using the URL shown in the terminal (usually):

```
http://localhost:3000
```
